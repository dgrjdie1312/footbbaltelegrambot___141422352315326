# FIELDUP Football Academy

Адаптивный сайт с формой заявки и Telegram-интеграцией.

## Добавлено
- Адаптация для телефонов, планшетов и компьютеров.
- Hover-эффекты на кнопках и карточках.
- Плавная прокрутка между секциями.
- Появление секций при прокрутке.
- Учитывается настройка `prefers-reduced-motion`.

## Запуск
Распакуйте архив и откройте `index.html`.

## Telegram
В `script.js` замените `YOUR_BOT_USERNAME` на username своего бота без `@`. Для автоматического приёма заявок требуется настроить логику бота/backend. Не размещайте токен бота в клиентских файлах.
